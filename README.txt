MACE LADDER KEYS MOD (client mod - every player installs it)
Needs Minecraft 26.3, Fabric Loader and Fabric API 0.161.0+26.3.

Build: upload everything in this folder to a NEW empty GitHub repo (keep the hidden .github folder),
open the Actions tab -> build -> download the artifact "mace-keys-mod" -> put the .jar in your mods folder.

Keys: Z = sky jump (change it in Options > Controls > Key Binds > Mace Abilities). Space twice in the air = double jump.
